# Documentary Website and App

Turn a prompt or topic into a documentary video.

## What this website can do

- Take any prompt or topic and make a documentary or story video from it.
- Choose a language: Roman Urdu, Urdu, Hindi, or English.
- Choose a length: 1 minute to 1 hour.
- Write scenes automatically from the prompt.
- Generate a matching picture for every scene — cinematic, photorealistic, exactly what the narration describes, with a different angle per scene.
- Play the video with the best narration voice — use the voice picker, choose speed Slow, Normal, or Tez, and use "Voice test karein" to preview a voice.
- Show subtitles matching the narration on every scene.
- Build long videos in batches with "Video aage badhao".
- Download the finished video as .webm and subtitles as .srt.
- Save projects under "Meri videos" and reopen them later.
- YouTube Publish Kit — make a ready title, description, and 10-15 hashtags, copy it, download it as .txt, or edit and save it.
